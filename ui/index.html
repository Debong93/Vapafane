CurseForge (optional) Experimentell

Brauche ich das? Nein – die meisten Mods gibt es auf Modrinth, das geht ohne Einrichtung. CurseForge findet zusätzlich Mods, die es nur dort gibt, und braucht dafür einen persönlichen API-Schlüssel (eine Art Zugangscode).

So bekommst du einen Schlüssel (kostenlos)
  1. Auf „Schlüssel beantragen“ klicken und das Formular ausfüllen (z. B. Zweck: „Mods für meinen eigenen Server“).
  2. Auf die Antwort per E-Mail warten – CurseForge prüft von Hand, das kann ein paar Tage dauern.
  3. Den Schlüssel unten einfügen, „Schlüssel testen“ und „Speichern“.

Der Schlüssel ist persönlich – nicht weitergeben oder veröffentlichen. Er bleibt nur auf diesem PC. Es gelten die CurseForge-Bedingungen für Drittprogramme. Experimentell: Ob CurseForge Schlüssel für private Tools vergibt, entscheidet CurseForge.

Über Vapafane

Vapafane – Minecraft-Werkbank für Server & Client

Vapafane ist kein offizielles Minecraft-Produkt. Es ist nicht von Mojang oder Microsoft genehmigt und steht in keiner Verbindung zu ihnen.

Minecraft ist eine Marke von Mojang/Microsoft. Mods und Plugins stammen von ihren jeweiligen Autoren (über Modrinth bzw. CurseForge).

Einladung einlösen

Code (beginnt mit VPF1-) einfügen oder die .vapafane-Datei öffnen – Vapafane richtet Minecraft mit allen Mods passend zum Server ein.

Meine Server

Vapafane startet Minecraft nicht selbst und fasst kein Microsoft-Konto an – „Spielen“ öffnet den offiziellen Launcher bzw. die Modrinth-App.
